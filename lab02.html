1. Define the Control Assertion

Lab 2. The Emergency Change. We must verify that all transports imported into production during the testing period were authorised, tested and approved before migration, and that migration access was restricted to appropriate personnel. Before opening SAP, define the production system and client, period, import population and what would constitute an exception. A change ticket is not evidence of timely approval unless its timestamps support the control assertion.

2. Extract Production Import History

Open S T M S, Import Overview, select the target production system, then Import History. Set the agreed testing period. Retain both selection criteria and complete results. For every transport capture request number, owner, import date and time, and return code. Reconcile the import history to the population definition. Preserve the raw export and work only on a copy.

3. Inspect SE01 and SCC4

Use S E zero one in display mode to inspect sampled transport requests, their attributes and object lists, including programs, table entries and configuration objects. Use S C C four in display mode to record production client change and transport settings. Do not edit. Preserve screen context, system, client and timestamps. These steps help identify what was imported and whether the production environment restricts changes.

4. Investigate the Six Emergency Imports

Match each production import to a change ticket. Compare approval time to import time, and verify that the importer belongs to the authorised Basis group. Classify missing tickets, approvals after import, and unauthorised importers separately. In the fictitious Thornfield case, six imports lacked matching approved tickets. They occurred over one weekend, outside business hours, by the same user. Tickets raised on Monday do not establish pre-implementation approval. One transport included an unrelated configuration change; management explanation alone does not close the exception.

5. Conclude and Submit Evidence

Build the evidence index: system status, S T M S selection and import history, S E zero one object lists, S C C four client settings and the exception classification reconciliation workbook. The case conclusion is that change management control did not operate for six production imports during a single incident without an emergency change procedure. Recommend a defined emergency approval window, mandatory business justification and post implementation review. Keep observed evidence, management explanations and unresolved reviewer questions distinct.
