Lab 1 — The Access List

Five existing instructional stages. This lab has no recorded MP3; Listen uses your browser's speech voice.

Interactive Lab 1 · Course homepage

1. Define the control objective

Verify no production user holds vendor-master-maintenance and payment-run execution access without a substantiated mitigation, for the defined company codes and snapshot.

Before entering SAP, document the production system/client, company codes, population, point-in-time snapshot, risk pairing and exception criteria. Obtain reviewer agreement on the scope.

Evidence: Signed scope worksheet, population definition and test criteria.

2. GRC access risk analysis

Identify unmitigated SoD conflicts and reconcile against the mitigated-inclusive population.

Run GRC Access Risk Analysis at User Level, Report Type Detail, procure-to-pay ruleset. Capture the first run with Include Mitigated Risks unchecked. Run again with that setting checked; retain both selection screens and exports.

Evidence: GRC selection criteria, timestamps, unmitigated and mitigated-inclusive result files and count reconciliation.

3. Trace access in SUIM / PFCG

Independently determine whether the flagged user obtains both capabilities through one role or separate roles.

In SAP GUI use /nSUIM to inspect Roles → By User Assignment. Use /nPFCG in Display mode for each relevant role, inspect Menu and Authorizations, and display authorization data. Do not modify roles.

Evidence: SUIM role assignment listing and PFCG display-only authorization trace, with SID/client and capture date.

4. Assess the case conflicts

Interpret the Thornfield training case without treating fictional counts as live SAP results.

Reconcile 41 case conflicts: 38 with recorded mitigation and 3 without. Trace the flagged user with both capabilities in one role. Record the three unmitigated conflicts as exceptions. Plan separate operating-effectiveness testing of the 38 recorded mitigations.

Evidence: Conflict count reconciliation, exception register, role trace and mitigation test population.

5. Conclude and prepare for review

Produce a conclusion that an independent reviewer can reperform.

Index the scope, two GRC exports, SUIM/PFCG traces and exception register. Conclude on the unmitigated SoD risk, recommend remediation of role design, and separately assess recorded mitigations. Clearly identify evidence gaps.

Evidence: Workpaper conclusion, evidence index, exception owner, remediation recommendation and reviewer signoff.
