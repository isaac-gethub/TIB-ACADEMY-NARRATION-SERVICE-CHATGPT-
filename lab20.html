Lab 20 — The Back Door

Five instructional sections. Browser narration; recorded MP3s pending. Open interactive lab

1. Inventory

Inventory custom Z and Y transactions. The case contains one hundred twelve, including nine sensitive transactions.

2. Authorization comparison

Compare custom ABAP authorization checks with SU24 standard checks. ZFI VENDOR QUICK omits the F LFA1 BUK object.

3. Restricted-user evidence

The approved restricted user test confirms vendor bank details could be changed through the custom transaction when the standard route blocked the user.

4. SCI review

Code Inspector identifies the same omitted check pattern in two additional custom transactions built by the same developer.

5. Conclusion

Recommend remediation of all three transactions and mandatory SU24 authorization review for future sensitive custom code.
