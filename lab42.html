Lab 42 — The In-House Bank

Five-part browser narrated lesson.

1. Netting population

Obtain the complete fiscal-quarter In-House Cash population: six intercompany netting runs across four entities.

2. SoD comparison

Compare each run's initiator and approver using the Treasury run log. Five have separate people; one quarter-end run has the same person in both roles.

3. Cause investigation

Trace the quarter-end exception to role design, assignment or coverage practices. Ask whether M. Alvarez's dual role is an isolated event or a recurring quarter-end practice.

4. Ledger reconciliation

Use SE16N to reconcile two sampled settlements to paying and receiving entity subledgers. Both match exactly, but this does not prove approval independence.

5. Conclusion

The quarter-end dual-role approval is a segregation-of-duties finding. Recommend a system-enforced initiator and approver separation in the In-House Cash workflow.
