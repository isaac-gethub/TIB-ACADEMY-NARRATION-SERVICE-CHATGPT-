TIB Academy Staff Portal v0.1

Functions:
- Staff-only Supabase login.
- Academy trainee list.
- Enroll / deactivate trainees in the three Academy courses.
- Submission review queue.
- Reviewer comments and submission status.
- Source-derived raw assessment item scoring.
- Automatic element percentage calculation.
- Certification eligibility display using the course rules.

Scoring sources encoded from the supplied TIB Course Guides:
Controls Lead:
- quizzes: Q1/Q2/Q3 pooled for half, Primer Final Assessment for half;
- practical: Find the Errors + Trace, with the <15 errors identified cap;
- CR-6 + CR-7;
- Module 9 planning pack;
- 70-point written capstone + 30-point presentation.
Security Lead:
- Modules 1–7 quizzes pooled;
- trace + incident practical;
- CR-S3 + CR-S6;
- Module 12 planning pack;
- 70-point written capstone + 30-point presentation.

Certification display:
75% overall, all elements >=70%, capstone >=70/100, presentation >=21/30.
