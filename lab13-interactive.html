Advanced controls testing — Fiori tile and backend authorization

Scenario: A user cannot see a sensitive application tile, but a tester suspects that backend access remains possible through another route.

  1. Document the user, business role, Fiori catalog, space/page assignment, OData service and relevant backend authorization scope.
  2. Test whether tile visibility and backend transaction/service authorization are independently restricted; distinguish user-interface hiding from effective access control.
  3. Collect configuration evidence and test outcomes for both an authorized and an unauthorized test identity.
  4. Record the control objective, procedure, exception criteria, impact, owner, remediation and retest evidence.

Required workpaper evidence: Scope, test identities, catalog/service mapping, test results, screenshots or logs from an authorized environment, and final control conclusion.

Assessment: Explain why a missing tile alone is insufficient proof of restricted access.
