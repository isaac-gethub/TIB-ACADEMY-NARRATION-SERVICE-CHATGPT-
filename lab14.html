Lab 14 — The Rule That Never Fired

Five instructional sections. Browser narration; recorded MP3s pending. Open interactive lab

1. Scope

Verify a GRC Process Control monitoring rule runs as scheduled, uses the intended population and identifies exceptions.

2. Execution history

Review the rule definition, data source, filters and six weeks of clean execution results.

3. Change history

Trace a data source change that made the rule assess an empty or incorrect population without documented approval.

4. Independent test

Use an independently known qualifying transaction to check whether the monitoring rule detects it. The case rule did not.

5. Conclusion

Document two linked findings: monitoring did not operate effectively and rule changes lacked approval controls.
