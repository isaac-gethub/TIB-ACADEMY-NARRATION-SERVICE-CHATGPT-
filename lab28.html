Lab 28 — The Depreciation That Kept Running

Five-part browser narrated lesson.

1. Execution

All twelve monthly depreciation runs completed without errors. Successful execution alone does not prove correct settings.

2. Transferred assets

Three assets transferred from an acquired entity retain inherited depreciation keys.

3. Useful life

AFAMA shows the inherited key uses a useful life forty percent longer than the standard for equivalent equipment.

4. Change history

Change history shows no correction for these three assets since transfer.

5. Conclusion

Review the depreciation key mapping, assess financial impact and document the required correction.
